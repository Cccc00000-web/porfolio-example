數位科技概論課程作業

本頁面記錄上課進行的 HTML、CSS 語法練習與各項單元作業。

HTML 基礎練習
  • 活動 01：文字層級與結構
    練習 h1-h3 語意化標籤、段落與文字風格標記 (sub, sup, b, i)
    作業 1 (學習小站) 作業 2 (科學探索日)
  • 活動 02：多媒體元件嵌入
    整合 PNG/SVG 圖片、WAV 音訊與 MP4 影片播放器控制條
    作業 1 (自然觀察站) 作業 2 (觀察任務卡)
  • 活動 03：清單與表格應用
    使用 ul 無序清單、ol 有序步驟清單以及 table 結構化表格
    作業 1 (學習計畫) 作業 2 (紙橋挑戰社)
  • 活動 04：互動表單設計
    實作單行文字、單選 (radio)、複選 (checkbox) 與下拉選單元件
    作業 1 (週末創作體驗) 作業 2 (社團體驗表)
CSS 樣式與排版練習
  • 活動 05：視覺風格與配色
    運用 CSS 屬性控制字型大小、留白 (padding/margin) 與 HEX 色彩
    檢視作業
  • 活動 06：整頁版型設計
    使用 CSS Grid (fr, minmax) 靈活調整單欄、雙欄與多欄佈局
    檢視作業
  • 活動 07：卡片排列與對齊
    透過 Flexbox 進行多卡片對齊，並用 object-fit 控制圖片裁切
    檢視作業
  • 活動 08：RWD 響應式網頁
    運用 @media 媒體查詢與 max-width 讓頁面隨裝置寬度縮放
    檢視作業
  • 活動 09：無障礙網頁設計 (A11y)
    透過 WAVE 進行機檢，修正對比度、alt 屬性與表單標籤連動
    檢視作業
