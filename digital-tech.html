數位科技概論課程作業

本頁面記錄上課進行的 HTML、CSS 語法練習與各項單元作業。

HTML 基礎練習
  • 活動 01：文字層級與結構
    練習 h1-h3 語意化標籤、段落與文字風格標記 (sub, sup, b, i)
    作業 1 (學習小站) 作業 2 (科學探索日)
  • 活動 02：多媒體元件嵌入
    整合 PNG/SVG 圖片、WAV 音訊與 MP4 影片播放器控制條
    作業 1 (自然觀察站) 作業 2 (觀察任務卡)
  • 活動 03：清單與表格應用
    使用 ul 無序清單、ol 有序步驟清單以及 table 結構化表格
    作業 1 (學習計畫) 作業 2 (紙橋挑戰社)
  • 活動 04：互動表單設計
    實作單行文字、單選 (radio)、複選 (checkbox) 與下拉選單元件
    作業 1 (週末創作體驗) 作業 2 (社團體驗表)
CSS 修改心得與實作觀察紀錄
各活動實作觀察紀錄：
【活動 05】我把 background 色碼改為 #ECDCBB，所以網頁頁面背景顏色變為淡黃色。
【活動 06】我選 c 版型，因為希望讀者先了解網站分別有什麼資訊後再依照個人需求選擇閱讀地方。
【活動 07】我選擇 cover，因為把畫面塞滿看起來比較舒服。
【活動 08】在窄視窗看到內容被畫面裁掉了，修正後內容會隨著畫面大小跟著調整空間，不管怎麼變動畫面長寬，網站內容永遠完整呈現出來。
【活動 09】
選擇微調的活動：活動 05 (視覺風格與配色)
原始問題與改善目標：我想改善週末故事創作社框框裡的內文，讓句子斷在剛好的地方，使視覺上看著更順暢。
具體修改程式碼：親手修改了 .card p { font-size: 19px; line-height: 1.8; } 這行，發現使用 19px 時，字的大小剛好在句點換下一行。
完成的修改內容：網頁背景顏色改為淡黃色 ( #ECDCBB )、大標題及內文調整為深咖啡色、中標題調整為紫色。
測試與驗證方式：在記事本中修改完成後存檔，切換至瀏覽器按重新整理觀看畫面改變結果。
