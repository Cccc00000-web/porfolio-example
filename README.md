# 📂 陳亭妤-個人作品集網站 (Portfolio Example)

這是我的個人作品集網頁設計專案，主要用於展示個人簡介、技能專長以及過去的專案成果。本網站已透過 GitHub Pages 成功架設並上線。

## 🌐 專案線上展示
* **網站動態展示網址：** [點此觀看我的作品集](https://github.io)
* **原始碼儲存庫：** [GitHub Repository](https://github.com)

## ✨ 網頁功能與特點
* **響應式網頁設計 (RWD)：** 支援手機、平板與電腦版網頁瀏覽。
* **個人簡介：** 包含自我介紹、學習歷程與核心技能展示。
* **作品集展示：** 條列式或卡片式呈現過往的專案成果與技術細節。
* **聯絡表單：** 提供點擊跳轉至 Email 或社群平台的聯絡管道。

## 🛠️ 使用技術
* **前端核心：** HTML5 / CSS3 / JavaScript
* **切版工具：** (例如：Bootstrap 5 / Tailwind CSS / 原生 CSS，請根據實際情況填寫)
* **網頁部署：** GitHub Pages

## 🚀 專案結構說明
```text
portfolio-example/
├── index.html # 網頁主首頁
├── css/ # 樣式表資料夾
│ └── style.css # 主要網頁視覺樣式
├── js/ # JavaScript 腳本資料夾
│ └── main.js # 網頁互動功能
└── images/ # 網頁使用的圖片、Logo 與 Icon
```
